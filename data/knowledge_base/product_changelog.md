# AquaPearl 500 Pro — Firmware Release Notes

## Firmware 2.5 — 2026-04-02
- Improved TDS reading stability at low flow.
- Filter-life countdown now shown in days in the app.

## Firmware 2.4 — 2025-11-15
- **Alert code change:** E-05 (continuous beeping) now means **internal leak detected**. On firmware 2.3 and earlier, E-05 meant UV lamp fault.
- The **UV lamp fault** alert has moved to **E-08** (two long beeps, blue LED off). On firmware 2.3 and earlier E-08 was reserved for service mode.
- Fixed an issue where the app would not pair on some Android 14 phones.
- Customers can check their firmware version in the app under Settings → Device.

## Firmware 2.3 — 2025-06-20
- Added the leak sensor hardware hook (inactive until 2.4).
- Faster reconnect after power cuts.

## Firmware 2.2 — 2025-02-11
- Quieter pump start-up.
- RESET hold time standardised to 5 seconds for all filter alerts.

## Firmware 2.1 — 2024-09-30
- First release with app support.
